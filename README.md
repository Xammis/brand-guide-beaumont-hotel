# Beaumont Hotel Brand Guide

Official Beaumont Hotel brand standards and assets packaged as an agent-compatible skill.

Give an AI agent this repository when creating a Beaumont Hotel design, document, report, webpage, presentation, email, social graphic, video graphic, or PDF:

```text
https://github.com/Xammis/brand-guide-beaumont-hotel
```

The skill includes official digital and print logos, etch backgrounds, icons, Libre Franklin web fonts, 1886 Coffee fonts, exact digital tokens, and documented public WordPress/frontend evidence.

Start with [`SKILL.md`](SKILL.md). Asset checksums and source-path provenance are recorded in the manifests under `logos/`, `backgrounds/`, `icons/`, and `fonts/`.

Adobe Illustrator source files are intentionally excluded from the background and icon deliverables.
